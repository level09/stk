```bash
uvx --from git+https://github.com/level09/stk stk init myapp && cd myapp
uv run stk db upgrade        # stk's migrations, then the app's
uv run stk doctor            # am I ready? every problem names its fix
uv run stk new invoice       # an extension: model, API, page, migration, at a URL
uv run stk verify --watch    # lint, sanity, migration drift on every save
uv run stk smoke             # a real browser, before you ship
```

	<Card title="A gate you can trust" icon="approve-check-circle">
