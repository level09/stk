## Overview

An async Quart framework for developers who ship. No build tools. No configuration maze. Just `./setup.sh && uv run stk run`.

stk combines Quart (async Python) with Vue 3 and Vuetify 4, without webpack, vite, or npm. Your AI assistant (Claude Code, Cursor) already knows the codebase thanks to built-in instructions.

## Key Features

- **Zero build step**: Vue 3 and Vuetify 4 run directly in the browser. No node_modules.
- **Auth that works**: 2FA, WebAuthn, OAuth (Google, GitHub). Production code, not a tutorial.
- **SQLite by default**: deploy anywhere, add PostgreSQL when you need it. Schema changes go through Alembic migrations.
- **Agent-operable**: ships with `AGENTS.md`, structured context, and one CLI: `stk`.
- **A gate you can trust**: `stk verify` and `stk smoke` check lint, sanity, migration drift, and real-browser behaviour, including text that renders invisible.
- **Complexity is opt-in**: Redis and PostgreSQL are optional add-ons (`uv sync --extra full`).

## Built for AI Agents

stk ships with `AGENTS.md` and structured context in `.stk/context/`, so AI assistants (Claude Code, Cursor, Copilot) understand the codebase instantly. Machine-readable introspection and verification close the loop:

- `stk inspect context --json` reports routes and models in one contract
- `stk doctor` reports the state of your checkout, each problem with the command that fixes it
- `stk verify --json` runs lint, sanity, and migration checks
- `stk smoke --json` drives a real browser through login and the dashboard
- `stk new <module>` scaffolds a complete module and its migration, ending at a URL you can open

Run `uv run stk --help` for the full command map, grouped by purpose. See [AI-Assisted Development](/ai-coding) for details.
